FAQ

How do I play?
Swipe rows and columns to sort colors so each quadrant contains only one color. Fewer moves = better score!

How does multiplayer work?
Create a room, share the code with friends, and race to solve the same puzzle in real time.

What are Challenges?
Photo puzzles created by the admin. Solve them and compete on the leaderboard for the best score.

How do I sign in?
You can sign in with Apple ID or play as a guest. Sign-in is optional for solo play.
